# Mare Nostrum

A turn-based strategy game on the map of the Mediterranean in 270 BC. Pick one of seven
civilisations, grow your cities, raise armies and defeat everyone else.

Plain HTML canvas, no build step, no dependencies. Open `index.html` through any static server:

```
node Tools/serve.mjs . 8060
```

Rules: `Docs/kurallar.md` (Turkish). Working notes: `Docs/working-on-this.md`.

Coastlines, lakes and rivers: [Natural Earth](https://www.naturalearthdata.com/) (public domain).
